# C++20 Exercises

These exercises focus on high-impact C++20 features used in modern production code.

## Suggested Order
1. [Exercise 1 - Concepts and requires clauses](01-concepts-and-requires.md)
2. [Exercise 2 - Ranges pipelines and views](02-ranges-pipelines.md)
3. [Exercise 3 - Coroutines with a simple generator](03-coroutines-generator.md)

## Build Note
Use a C++20-capable compiler, for example:

```bash
g++ -std=c++20 -Wall -Wextra -pedantic main.cpp -o app
```
