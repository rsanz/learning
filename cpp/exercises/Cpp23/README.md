# C++23 Exercises

These exercises target key C++23 additions that are highly useful in everyday modern C++ code.

## Suggested Order
1. [Exercise 1 - std::expected for explicit error handling](01-expected-error-handling.md)
2. [Exercise 2 - Deducing this for cleaner member APIs](02-deducing-this.md)
3. [Exercise 3 - Ranges improvements with views::zip](03-ranges-zip.md)
4. [Exercise 4 - std::print and stacktrace for diagnostics](04-print-and-stacktrace.md)

## Build Note
Use a C++23-capable compiler, for example:

```bash
g++ -std=c++23 -Wall -Wextra -pedantic main.cpp -o app
```
