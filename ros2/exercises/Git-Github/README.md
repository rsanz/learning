# ROS 2 Git-GitHub Exercises

These exercises help you practice the collaborative workflow described in the Git-Github tutorial.

## Prerequisites
- Linux shell access
- Git configured with your name and email
- A GitHub account
- A ROS 2 workspace (for example: `~/ros2_ws`)

## Exercise Path
1. [Exercise 1 - Repository Structure and .gitignore](01-repository-structure-and-gitignore.md)
2. [Exercise 2 - Feature Branch Workflow](02-feature-branch-workflow.md)
3. [Exercise 3 - Multi-Repo Dependencies with vcstool](03-multi-repo-dependencies-with-vcstool.md)
4. [Exercise 4 - CI and Pull Request Quality Gates](04-ci-and-pr-quality-gates.md)

## How to Use
- Complete exercises in order.
- Keep notes of commands you ran and problems you hit.
- Treat each exercise like a real team workflow, not a one-off script.
